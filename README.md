# Агент идей для контента

Каждое утро агент предлагает **3 идеи постов** для бренда с учётом:
- актуальных инфоповодов (RSS-ленты новостей);
- ближайших праздников и памятных дат (`data/holidays.json`);
- профиля бренда (`config/brand.json`).

Результат сохраняется в `output/ГГГГ-ММ-ДД.md` и (опционально) присылается в Telegram.

Зависимости не нужны — только Python 3.9+ и ключ API Anthropic.

## Структура

```
agent.py              # основной скрипт
config/brand.json     # профиль бренда: описание, аудитория, тон, темы, рынки
config/sources.json   # RSS/Atom-ленты с новостями (URL или путь к файлу)
data/holidays.json    # праздники: "MM-DD", название, страны (RU, KZ, INT)
output/               # дайджесты по дням (не в git)
```

## Быстрый старт

1. Заполните `config/brand.json` — название, аудиторию, тон, темы, «чего избегать».
2. При необходимости поправьте `config/sources.json` и `data/holidays.json`.
3. Проверьте сборку данных без вызова модели:
   ```bash
   python3 agent.py --dry-run --no-telegram
   ```
4. Запустите с ИИ-генерацией:
   ```bash
   export ANTHROPIC_API_KEY=sk-ant-...
   python3 agent.py --no-telegram
   ```

Полезные флаги: `--date 2026-12-31` (считать «сегодня» другой датой), `-v` (подробные логи).
Модель берётся из `brand.json` (`model`) или переменной `CONTENT_AGENT_MODEL`.

## Ежедневный запуск

### Вариант 1: cron на сервере

```cron
# каждый день в 08:00 по времени сервера
0 8 * * * cd /path/to/Adilya-agent && ANTHROPIC_API_KEY=sk-ant-... TELEGRAM_BOT_TOKEN=... TELEGRAM_CHAT_ID=... /usr/bin/python3 agent.py >> cron.log 2>&1
```

Учтите часовой пояс сервера. Если нужно строго по местному времени, задайте `CRON_TZ=Asia/Almaty` (или ваш пояс) первой строкой crontab.

### Вариант 2: Telegram-доставка

Создайте бота через @BotFather, узнайте `chat_id` и задайте переменные:
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. Если переменных нет, отправка пропускается.

### Вариант 3: Hermes Agent

Агент можно запускать как задачу по расписанию в [Hermes Agent](https://github.com/NousResearch/hermes-agent):
в его планировщике (cron) укажите команду `python3 /path/to/Adilya-agent/agent.py` и доставку результата в нужный канал.

## Что делает агент, пошагово

1. Читает профиль бренда и список праздников; выбирает даты в окне `holiday_horizon_days` (по умолчанию 7 дней) с учётом рынков бренда.
2. Скачивает заголовки из лент. Недоступная лента пропускается с предупреждением и не останавливает работу.
3. Отправляет модели профиль, праздники и заголовки с системной инструкцией: предлагать только идеи на основе переданных данных, не выдумывать новости, соблюдать ограничения бренда.
4. Разбирает ответ (ожидается JSON из 3 идей: заголовок, крючок, формат, площадка, почему сейчас, черновик).
5. Сохраняет Markdown-дайджест и печатает его в stdout.

Если ключа API нет или запрос к модели упал, агент всё равно сохраняет праздники и заголовки — для ручного брейнсторма.

## Важно

- **Сетевой доступ.** Ленты и `api.anthropic.com` должны быть доступны с сервера. Если RSS-хосты заблокированы, добавьте их в разрешённые или замените источники на свои.
- **Актуальность праздников.** Даты «ориентировочно» (например, Чёрная пятница) проверяйте ежегодно; переходящие праздники (Курбан-айт, Ураза-айт, Пасха) лучше добавить вручную с датой на нужный год.
- **Качество идей.** Модель опирается только на переданные данные. Чем точнее профиль бренда и список тем, тем полезнее идеи.
- **Ключи.** Не храните `ANTHROPIC_API_KEY` и токены Telegram в репозитории — только в переменных окружения или секретах планировщика.
